# 后续计划

当前已交付内置 Python 的 macOS Apple Silicon 双击启动测试包，以及网页扫描、模型下载、暂停续传和识别管理。以下项目尚未交付，不能作为当前功能承诺。

1. **正式发行**：维护者配置 Developer ID，完成 Apple 公证，在不同 macOS 版本验证首次打开、系统照片权限和升级。界面继续使用系统浏览器。
2. **数据可靠保存**：资产、人工标签、活动名称和任务存入统一 SQLite；提供现有浏览器 localStorage 的导入与冲突处理。
3. **减少加载开销**：静态前端与按需查询 API，连续滚动、增量数据及图片懒加载；保留各视图滚动位置。
4. **更多本地模型**：在不同芯片和内存机器上测量模型质量与速度，再增加经过验证的选项；基础整理继续不依赖大模型。
5. **Windows 适配**：普通文件夹来源、回收站、系统 OCR 与本地推理后端；使用同一界面和数据格式，经过实机测试再标注支持。

保留用户勾选确认、收藏／隐藏保护和异常删除回执。不会因为分类或相似度自动删除，也不增加强制逐张复核流程。多设备计算协作不在当前计划中。
