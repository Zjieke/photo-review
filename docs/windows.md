# Windows 安装与使用

面向 Windows 10 1809 或更新系统、Windows 11 x64。下载 Release 中的 `Windows-x64-Setup.exe`，双击安装，完成后打开浏览器。安装程序按当前用户安装，不需要管理员权限，不要求安装 Python、Ollama、CUDA 或编译工具。以后双击桌面或开始菜单的“照片整理”即可。另提供 ZIP 便携版，必须完整解压后打开 `PhotoReview.exe`。

测试版尚未做 Authenticode 签名，Windows 可能提示未知发布者；本项目不提供关闭系统安全防护的脚本。浏览器是唯一产品界面，EXE 负责启动、日志、文件夹选择和子进程生命周期。

## 选择照片来源

在“图库与模型”选择照片文件夹，再开始扫描。可选择普通图片目录、iCloud for Windows 或 OneDrive 中已下载到本机的目录。在线占位文件、符号链接、目录联接和不可访问文件会跳过，不会因扫描而自动下载云端原片。需要整理这些照片时，应先使用对应同步客户端将其下载到本机，再重新扫描。

基础整理包括缩略图、系统离线 OCR、规则标签、按日期与体积的活动分组、重复与相似图片。Windows OCR 使用系统已有语言包；没有可用识别语言时仍可整理文件和缩略图，可在系统中添加相应语言后重新扫描。日期优先采用照片 EXIF，缺少时使用文件修改时间；视频目前使用文件修改时间。

勾选并确认删除后，原文件移入 Windows 回收站。服务只接受已扫描的文件编号，删除前核对选中目录、文件是否在本机及大小／修改时间／文件身份；变化过的文件需重新扫描。iCloud、OneDrive 等同步目录中的删除可能同步到云端和其他设备。程序不会绕过回收站永久删除文件。

## 可选模型

在网页中下载 Qwen3-VL 2B Q8，语言模型与视觉投影共约 2.3 GB。支持进度、暂停、续传、校验和失败重试。建议 8 GB 以上内存；当前版本使用 CPU，速度取决于机器。权重与照片分开，安装包不附带模型。下载完成后可断网识别。

本地模型服务绑定随机的 `127.0.0.1` 端口并使用随机令牌，仅由识别进程调用。打开程序不会自动扫描、下载或识别。暂停识别会完成当前图片并保存结果；下次继续复用缓存。

## 数据和退出

程序默认安装到 `%LOCALAPPDATA%\Programs\Photo Review`，用户数据位于 `%LOCALAPPDATA%\Photo Review`。模型、扫描缓存和预览与安装文件分开；更新和卸载保留用户数据。手工标签和活动名称仍保存在当前浏览器、当前访问地址的 localStorage，换浏览器或清理站点数据不会自动迁移。

关闭浏览器后任务可继续，在“图库与模型”点击“退出程序”保存进度并停止后台进程。重复打开快捷方式会复用已有服务。启动日志位于数据目录的 `logs\launcher.log`；后台任务与本地引擎日志位于 `work`。

## 维护者构建

构建机需要 Windows x64、Python 3.12+、系统 .NET Framework C# 编译器及 Inno Setup 6；最终用户不需要这些工具。

```powershell
python scripts/build_windows.py --version 0.3.0-preview.2
python scripts/smoke_windows.py dist/Photo-Review-0.3.0-preview.2-Windows-x64.zip --inference
```

运行包已包含应用本地的 Microsoft C++ 运行库，不要求安装全局 VC++ Redistributable。构建和安装验收会逐一核对 PE 导入及 DLL 导出符号，避免借用构建机预装的运行库。

构建脚本按固定 SHA256 下载 Astral 官方 CPython 3.12.15 与 llama.cpp b11829 Windows CPU 发布包，安装固定版本依赖，按源码白名单拷贝程序，编译启动器并创建当前用户安装程序。模型另行下载，照片与私人数据库不会进入安装包。

GitHub Actions 的 `Build Windows browser launcher` 手动构建，并在 Windows 运行器中完成原生安装、中文路径启动、系统 OCR、合成图片扫描、模型下载与真实推理、缓存复用、合成文件回收站删除、重复启动、退出及卸载保留数据的验收。测试使用人工生成的图片，不访问个人图库。
